☁️ Google Drive Bağlantısı

Drive'dan dosya açabilmek için Google Cloud Console'dan API anahtarları gereklidir. console.cloud.google.com adresinden:

  1. Yeni proje oluşturun
  2. "Google Drive API" ve "Google Picker API" etkinleştirin
  3. Kimlik Bilgileri → OAuth 2.0 Client ID (Web application) oluşturun
  4. Kimlik Bilgileri → API Key oluşturun
  5. Aşağıya yapıştırın ve kaydedin
